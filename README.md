Entry for make.fun bounty **The One-Line Laugh** ($5 pool): one original
funny line, any topic, at most 200 characters, judged pairwise by a house
judge that keeps the bigger laugh.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> I pay for a gym membership every month so a building across town can believe in me more than I do.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
